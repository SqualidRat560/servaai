# ServaAI

Forecasts a Tangerine customer's next 3 months of balance, updates instantly when life happens
(a layoff, a rent hike, a scam), and builds a Tangerine plan. Sheridan Datathon 2026, Tangerine track.

- `backend/`: Python engine (judge runway, realistic runway, forecast, plan), Gemini event agent, FastAPI
- `frontend/`: React + Vite + react-three-fiber
- `powerbi/`: portfolio dashboards
- `docs/`: decisions, backtest, findings

Data (`data/`) is the track-provided dataset and is not committed. Run steps follow in later phases.
